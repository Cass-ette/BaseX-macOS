This repository is an unofficial packaging wrapper for BaseX.

- Upstream project: https://basex.org/
- Upstream source and downloads: https://files.basex.org/releases/

This repository does not claim ownership of BaseX itself.

When distributing built artifacts from this repository:

- keep the upstream BaseX license and notices intact
- clearly state the packaged BaseX version
- avoid implying official endorsement by the BaseX project
